📱 HƯỚNG DẪN CÀI SCRIPT CHO IPHONE & ANDROID

🤖 Dành cho ANDROID (Dùng ZArchiver)

  1. Tải file .zip từ Web Tool về máy → Giải nén bằng ZArchiver.
  2. Sao chép file Mod vừa giải nén (file OBB mã gốc hoặc thư mục mod).
  3. Truy cập đường dẫn chuẩn:
    Android/data/com.dts.freefireth/files/contentcache/Compulsory/android/gameassetbundles/
  4. Bấm DÁN (Paste) và chọn Thay thế (Replace).
  5. Mở Game vào trận đặt Bom Keo ra để tận hưởng!

🍏 Dành cho IPHONE (Dùng Filza)

  1. Tải file .zip từ Web Tool → Mở app Tệp (Files) nhấp giải nén.
  2. Mở Filza File Manager → Copy file mod vừa giải nén.
  3. Truy cập đường dẫn:
    Containers/Data/Application/Free Fire/Library/Caches/Compulsory/android/gameassetbundles/
  4. Bấm DÁN và chọn Thay thế (Replace).
  5. Mở game để trải nghiệm!

🧊 Cách Cài Mod Skin Bom Keo Từ Ảnh (Menu 2)

  1. Bấm chuyển sang MENU 2 → Chọn/Tải ảnh bất kỳ từ điện thoại lên.
  2. Bấm CHUYỂN ẢNH THÀNH SKIN BOM KEO & TẢI VỀ.
  3. Giải nén file ZIP nhận được → Lấy file OBB mã gốc vừa tải.
  4. Dán đè vào đúng thư mục gameassetbundles ở trên.
  5. Vào game đặt Bom Keo ra để chiêm ngưỡng Skin ảnh tự chọn cực ngầu!
